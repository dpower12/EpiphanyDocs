    Throwing Bag

    Throwing Bag is an active item that serves as Tarnished Cain's primary method of attacking, throwing the bag and needing to collect it to attack again. Throwing Bag can absorb two items in order to make additional bags to throw, each item contributing a unique effect to the bag it was crafted into. If the item is collected on its own, it may also provide a unique synergy to all of the player's bags.

    Epiphany's API allows for adding your own custom synergies for Throwing Bag. This guide will cover the large array of options available for customizing its effect.

    Adding to existing synergies⚓︎

    While Throwing Bag has unique synergies for many notable items, it also has a wide array of synergies that group many items together, all contributing to the same bag effect. This is an easy shortcut to giving an item a Throwing Bag synergy, especially for other mods that may not want to take the time to make completely unique synergies from scratch. To contribute an item to an existing synergy, the function Epiphany.API:AddCollectibleToCainBagSynergy(syngergyName, collectibles) accepts an identifier string and an individual or array of CollectibleTypes. Below is a full list of available generic synergies and what items should be part of it. To view the existing items already present in these synergies and their effects, see this page on the official Epiphany wiki.

    Exclude

    In some cases you may want to create a unique synergy for an item with a specific tag that doesn't contribute to a different synergy. For this, use the function Epiphany.API:ExcludeItemFromTagSynergy(itemTag, collectibles) which accepts a tag from the ItemConfig enumeration to target and an indivudal or array of CollectibleTypes.

    Creating custom synergies⚓︎

    Adding synergies is done through one largely customizable function:

    1
    function Epiphany.API:AddCainBagSynergy(synergyName: string, synergyTable:table): table

    synergyName can be anything so long as it does not conflict with an existing synergy name. The usual naming convention for Throwing Bag synergies within Epiphany is using snake case, the name of the item os group name, and whether its bagged, passive, or universal. For example, a bagged synergy for Binge Eater would be "binge_eater_bagged", and a passive synergy for brimstone would be "brimstone_passive".

    synergyTable will be split into two sections: Basic variables, and callback variables. The callbacks may have their system improved in the future (notably, becoming actual callbacks), but their current implementation will still be covered. There are also actual Throwing bag-related callbacks, which you can find here.

    Basic variables⚓︎

    Throwing Bag synergy variables
    Variable Name Possible values Description
    id_list CollectibleType[] Required. List of collectibles that contribute to the synergy.
    flags BagSynergyFlags Required. Determines synergy behaviour of when its active.
    sprite_path string or function Can be a string path to an anm2 file for the throwing bag, or a function, which is structured like so:
    fun(EntityPlayer, BagData, BagsInfo):string?
    color Color Color applied to the bag. If more than one item in a bag has a color assigned, the color will be lerped between them
    burst_color Color Color of tears spawned when the bag impacts a wall, obstacle, or enemy
    burst_params BurstParamsConfig List of parameters for customizing the tears that spawn when the bag impacts a wall, obstacle, or enemy
    callback_priority integer Determines the order in which the callbacks are called. Higher priority values go first. Applies to all callbacks added in the table
    gfx_priority BagGFXPriority Determines priority of synergy graphics. Higher priority values go first
    parent string Name of existing synergy to parent this synergy to. Will inherent all properties from the parent synergy

    Callback variables⚓︎

    Some of these callbacks can already be found as actual callbacks under Epiphany.ExtraCallback, but serve as for more generic cases, while the callbacks here only run for the assigned synergy. None of these callbacks accept any return parameters.

    Throwing Bag callback synergy variables
    • callback_swing: fun(bag:EntityEffect, count:integer, player:EntityPlayer, bagData:SwingingBagData)
      Called when the bag starts swinging.
    • callback_pre_swing: fun(bag:EntityEffect, count:integer, player:EntityPlayer, bagData:SwingingBagData)
      Called right before callback_swing. Can be used to modify bag contents.
    • callback_swing_update: fun(bag:EntityEffect, count:integer, player:EntityPlayer, bagData:SwingingBagData)
      Called every frame for each bag that is swinging.
    • callback_post_bomb_insert: fun(bag:EntityEffect, bomb:EntityBomb, count:integer, player:EntityPlayer, bagData:SwingingBagData)
      Called when a bomb is inserted into the bag.
    • callback_throw: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called when the bag is thrown.
    • callback_pre_throw: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called right before callback_throw. Can be used to modify bag contents.
    • callback_flying: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called every frame while the bag is flying.
    • callback_update: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called every frame while thrown bag is flying or on the ground.
    • callback_pre_hit: fun(bag:EntityEffect, count:integer, entity:Entity, bagData:ThrownBagData)
      Called before thrown bag hits an entity.
    • callback_post_hit: fun(bag:EntityEffect, count:integer, entity:Entity, bagData:ThrownBagData, dmgDealt:integer)
      Called after thrown bag hits an entity.
    • callback_hit_bullet: fun(bag:EntityEffect, count, bullet:EntityProjectile, bagData:ThrownBagData)
      Called when the thrown bag hits an enemy bullet.
    • callback_hit_grid: fun(bag:EntityEffect, count:integer, gridEntity:GridEntity, bagData:ThrownBagData)
      Called when the thrown bag hits a grid entity.
    • callback_swing_pre_hit: fun(bag:EntityEffect, count:integer, entity:Entity, player:EntityPlayer, bagData:SwingingBagData)
      Called before thrown bag hits an entity while swinging.
    • callback_swing_post_hit: fun(bag:EntityEffect, count:integer, entity:Entity, player:EntityPlayer, bagData:SwingingBagData, dmgDealt:integer)
      Called after thrown bag hits an entity while swinging
    • callback_swing_hit_bullet: fun(bag:EntityEffect, count:integer, bullet:EntityProjectile, player:EntityPlayer, bagData:SwingingBagData)
      Called when thrown bag hits a projectile while swinging.
    • callback_unload: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called when the bag shoots out rocks.
    • callback_fall: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called when the bag falls to the ground.
    • callback_recall: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called when the bag is recalled.
    • callback_remove: fun(bag:EntityEffect, count:integer, bagData:ThrownBagData)
      Called when the bag is removed.
    • callback_swing_update_combined: fun(player:EntityPlayer, count:integer, combinedBagData:BagData)
      Called every frame while the player is swinging any amount of bags. combinedBagData contains the contents of all bags the player is currently swinging, added together.
    • callback_swing_combined fun(player:EntityPlayer, count:integer, combinedBagData:BagData)
      Called when the player starts swinging any amount.
